# Generated views have no third-party runtime

Accepted. Python generates the diagrams and the repository owns the CSS and
optional app script; no runtime library, CDN, fetched asset, Node build or second
serialized corpus is introduced. A chart/UI dependency would trade a small
amount of local rendering work for supply-chain, offline-read and byte-stability
obligations that conflict with portable evidence views; pytest remains the sole
development dependency, and browser verification is separate from runtime code.
