# Retrieval is discovery, not validation

Consultation must find relevant memory entries and knowledge units before an
agent repeats investigation, while preserving their different evidence and
supersession contracts. We add read-only, bounded retrieval over safely acquired
original documents; existing indexes remain unchanged and no search cache is
stored. Relevance never certifies applicability, and an anchor verdict never
certifies the complete claim.

Invalid or unreadable requested inputs fail explicitly with no usable results.
We accept lower availability in imperfect corpora over silently presenting
partial evidence as a complete search. Excerpts are discovery aids requiring
source inspection; automatic probes, semantic services and mandatory action
gates are outside this increment. See the
[specification](../plans/memory-reuse/specification.md) for acquisition limits
and the distinction between complete input coverage and bounded output.
