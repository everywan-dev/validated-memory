# Review findings, one file per unit

Written by the review described in
[`../2026-09-03-codebase-review.md`](../2026-09-03-codebase-review.md). Each
unit gets `<unit>.md` here: what was found along each axis, what was applied,
what was deferred and where it went, and what was rejected with the reason.

The plan holds the state; these files hold the reasoning, so the plan stays
short enough to read at the start of every session.
